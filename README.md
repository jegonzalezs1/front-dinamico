# FrontEnd Prueba

Esta es una prueba de front basada en formularios dinámicos

## Requerimientos

### Variables de entorno

- urlAddress: http://localhost:44306 (Local)
  
- urlAddress: http://localhost:8085 (Docker)

### Estructura del portal

Campo:
- form-input-edit
- form-input-list
  
Formulario:
- form-view
- form-list
- form-edit

## Pasos para la ejecución del Front

1.- Depurar con ng build o npm run start

2.- Se muestra la pantalla principal del Front 

3.- Seleccionamos con un clic la opción Formulario

![image](https://github.com/user-attachments/assets/43ebfded-ebd9-4a03-aa3b-d3ef3ffc2fbf)

4.- Dentro de la opción Formulario, si queremos crear uno, hacemos clic en el botón "Crear nuevo formulario"

![image](https://github.com/user-attachments/assets/98469d08-5595-41a0-8dc1-c5ec659b7727)

5.- Se nos aparece el modal de Formulario, ingresamos los datos y hacemos clic para Guardar, si queremos modificar el nombre seleccionamos la opción Actualizar y si lo eliminamos hacemos clic en la opción eliminar

![image](https://github.com/user-attachments/assets/ee006325-d782-4a3c-ad51-34175440ad26)

6.- Luego de haberse creado el Formulario, salimos de esa opción y damos atrás al navegador de la página

7.- Seleccionamos con un clic la opción Campo

![image](https://github.com/user-attachments/assets/077dd019-9ed7-4dfc-a047-473fbc7e4e37)

8.- Se nos aparece el modal de Campo, ingresamos los datos y seleccionamos el formulario Creado, hacemos clic para Guardar, si queremos modificar el Campo seleccionamos la opción Actualizar y si lo eliminamos hacemos clic en la opción eliminar

![image](https://github.com/user-attachments/assets/60873dbf-4991-4749-b58b-a92638d4f2c0)

9.- Luego de haberse creado los campos, salimos de esa opción y damos atrás al navegador de la página

10.- Para verificar si todos los formularios se han creado correctamente, hacemos clic en Visualizar dentro de la opción de Formularios

![image](https://github.com/user-attachments/assets/751c773a-e206-403e-94ad-1f4edef8b0b3)

Listo ya tenemos nuestro formulario dinámico a través de un Backend
